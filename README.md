## 🚀 Getting Started

### Hardware

The projects in this repository primarily use:

* Arduino Uno
* LEDs
* Buzzers
* Push buttons
* PIR sensors
* LDR sensors
* Ultrasonic sensors
* LCD displays
* Servo motors
* Potentiometers
* Jumper wires
* Breadboards

Individual projects may require additional components.

### Software

The projects are developed using:

* **Arduino IDE**
* **C/C++**
* **VS Code** where applicable

### How to Open a Sketch

1. Clone or download this repository.

2. Open **Arduino IDE**.

3. Navigate to the project you want to run.

4. Open the project's `.ino` file.

5. Connect the required Arduino board.

6. Select your board under:

   **Tools → Board → Arduino Uno**

7. Select the correct port under:

   **Tools → Port**

8. Click **Verify** to compile the project.

9. Click **Upload** to upload the sketch to the Arduino.

Each project folder contains instructions specific to the hardware and software required.
