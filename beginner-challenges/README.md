# 🧪 Beginner Challenges

Welcome to the **Experiment** section of Arduino Starter Lab.

These challenges are designed to help you go beyond copying a project.

**Build → Change → Break → Debug → Improve**

You can complete these challenges after working through the weekly projects.

---

## 💡 Challenge 1 — Automatic Night Light

**Based on:** Week 1 — Light-Activated LED

### 🎯 Goal

Modify the Light-Activated LED so that it behaves more like a real automatic night light.

### Try to:

* Change the light threshold
* Add a second LED
* Make the LED turn on only when it is very dark

**Difficulty:** 🟢 Beginner

---

## 🔢 Challenge 2 — Binary Counter

**Based on:** Week 2 — 7-Bit Random Number Display

### 🎯 Goal

Modify the project so that the LEDs count upward instead of displaying random numbers.

For example:

```text
0 → 1 → 2 → 3 → 4 → ... → 127
```

### Try to:

* Use a button to start the counter
* Control the counting speed
* Make the counter reset after 127

**Difficulty:** 🟢 Beginner

---

## 📏 Challenge 3 — Smarter Proximity Alarm

**Based on:** Week 5 — Ultrasonic Proximity Alarm

### 🎯 Goal

Make the alarm respond differently depending on how close an object is.

For example:

```text
> 50 cm       → No alarm

20–50 cm      → Slow warning

< 20 cm       → Fast warning
```

### Try to:

* Change the distance thresholds
* Change the buzzer pattern
* Make the buzzer faster as the object gets closer

**Difficulty:** 🟡 Beginner+

## 🚀 Want to Create a Challenge?

You can contribute your own beginner challenge.

Open an issue using the **Project Idea** or **Enhancement** option and explain:

* What the learner should build
* Which project it is based on
* What they will learn
* The difficulty level
